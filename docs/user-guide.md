# 随想随记 · 用户手册

本手册对应 **1.0.0**（2026-11-02），面向使用者，覆盖目录、编辑器、右键菜单、快捷键、
回收站、设置、导入导出和窗口操作。安装方式见
[`README.zh.md`](../README.zh.md)，实现细节见 [`architecture.md`](architecture.md)，
数据格式见 [`storage.md`](storage.md)。

## 1. 打开与关闭

插件装好并重启 DSH 后，左侧侧栏底部会出现一个便签图标：

- **点击图标**：隐藏或重新显示悬浮窗。图标处于按下状态表示当前正在显示。
- **隐藏后**：窗口和圆球都不出现，但便签数据仍然保存在本地；再点图标即可回来。
- **刷新页面或重启 DSH**：窗口会按上次保存的模式恢复，隐藏状态也会被记住。

悬浮窗本身浮在整个界面之上，不会打断当前会话。它固定在屏幕坐标系里，可以盖住聊天
区域，也可以用标题栏拖到不挡内容的位置。

## 2. 界面布局

普通模式由四个部分组成：

1. **顶部移动条**：按住可以拖动整个窗口；右侧是「仅便签」「缩成圆球」「恢复默认大小」
   三个按钮。
2. **左侧目录**：便签列表、新建按钮，底部是设置、回收站、横线衬底开关和同步状态。
3. **右侧编辑器**：当前便签的标题（双击可重命名）、字数、更新时间和正文区域。
4. **底部状态**（目录栏底部）：设置入口、回收站入口、横线衬底开关、同步状态小圆点。

目录与编辑器之间有一条分隔条，左右拖动可以改变目录宽度（120–320 px）。目录变窄时
便签标题会截断显示，鼠标悬停可以看到完整标题。

## 3. 便签目录

### 新建便签

1. 点目录顶部的 `+` 按钮。
2. 列表里会出现一行输入框并自动获得焦点，输入便签名称。
3. 按 `Enter` 确认创建，按 `Esc` 取消；输入了非空名称时，点击输入框外面（失焦）
   也会创建；空名称失焦则直接取消，不会凭空生成便签。
4. 名称留空时直接按 `Enter` 确认，会创建一条「未命名便签」；之后可以随时重命名。

新建的便签会自动选中，可以直接开始写。

### 重命名

- **双击**目录中的一行，进入重命名输入框；行获得焦点时按 `F2` 也可以重命名。
- `Enter` 确认，`Esc` 取消；输入非空时失焦也会确认，清空名称后失焦则保持原名。
- 名称会去掉首尾空白，连续空白合并成一个空格，最长 80 个字符。

### 置顶

- 鼠标移到便签行上，右侧会出现置顶按钮；点击后这条便签排到列表最前面。
- 再次点击取消置顶，回到未置顶分组。
- 置顶只改变显示顺序，不会改变便签的创建时间或内容。

### 拖拽排序

- 按住便签行上下拖动即可调整顺序；移动超过 4 px 才开始拖动，普通单击 / 双击不受影响。
- 排序只发生在同一组内：置顶的便签在置顶组内移动，普通便签在普通组内移动，拖到组
  边界会停在边界，不会跨组。
- 拖动时被拖的行跟手，其他行平滑让位；松手后新顺序立即保存，刷新后保持。
- 键盘：聚焦某行后按 `Alt` + `↑`/`↓`，把该便签在组内上移 / 下移一格。

### 选择与删除

- 单击一行即可切换当前便签。
- 删除按钮把便签移入回收站（软删除），不会立即消失。
- 如果删除的是当前选中的便签，会自动选中列表中的第一条；没有便签时显示空态提示。

### 空态与数量上限

- 没有任何便签时，目录和正文都会给出引导文案，点新建即可开始。
- 目录最多保存 **500 条便签**；达到上限后无法继续新建，需要先删除一些便签。
- 便签名称最长 **80 个字符**，单条便签的 HTML 最多 **60 万个字符**（内嵌图片也计算
  在内）。
- 一次保存的请求体最大 **8 MiB**，图片较多时会更快接近这个上限。

### 目录宽度

拖动目录与编辑器之间的分隔条调整宽度，范围 120–320 px，默认 176 px。宽度会和窗口
位置一起保存，下次打开保持原样。

## 4. 编辑器

### 头部信息

编辑器顶部显示当前便签标题、字数统计和更新时间。标题**双击可重命名**：双击后变成
输入框并自动全选，`Enter` 提交、`Esc` 取消、点击别处（失焦）也会提交；清空名称则保持
原名。没有选中便签时，正文区显示「选择一条便签，或新建一条」的提示。

### 正文与自动保存

- 正文是富文本编辑区，输入、删除、粘贴都会立即更新到内存。
- 持久化有 500 ms 防抖：停止输入约半秒后，统一写入浏览器本地镜像和 Host 文件；
  连续输入期间不会每个按键都落盘。
- 页面关闭 / 刷新前会把尚未写盘的内容补写一次；切换便签、隐藏窗口不会丢内容。
- 不需要手动保存，也没有「保存」按钮。

### 空便签

空便签的正文区保持干净：不再显示占位提示文案，直接开始输入即可。

### 横线衬底

点目录左下角、**回收站右侧**的三横线按钮，可以打开 / 关闭正文横线（按钮按下状态表示
已开启）。横线间距跟随当前字号与行高；开关状态会随便签一起保存。

### 粘贴

- 从网页或文档粘贴时，插件会先清洗 HTML，只保留允许的标签和格式，再插入编辑器。
- 纯文本粘贴会按纯文本插入，不会带进外部网页的样式。
- 把文字或网页内容直接拖进编辑器也会先清洗 HTML，与粘贴使用同一份白名单。
- 粘贴后的内容同样会被保存，且不会引入脚本、图片链接等不安全内容。

### 粘贴 / 拖入图片

- 支持 PNG、JPEG、WebP、GIF 图片：从剪贴板粘贴，或直接把图片文件拖进正文即可。
- 图片会被**等比压缩**后内嵌到便签里：最长边缩到不超过 1024 px；如果生成的
  data URL 超过大小预算，会继续按比例缩小，最低到 320 px。
- 插入后图片按编辑器宽度显示（最大 100% 宽、高度自适应），大截图不会撑破窗口。
- 图片是便签 HTML 的一部分，没有独立附件文件；单条便签的 60 万字符上限包含图片。
- 外链图片、SVG、无法解码的图片会被忽略；多张图片累计超过便签大小上限时，后面的
  图片会被跳过（不会弹出提示）。
- 带透明通道的图片会保留透明：PNG / WebP / GIF 输入按 PNG 编码，JPEG 输入按 JPEG
  编码；动态 GIF / WebP 只保留第一帧。

## 5. 富文本与右键菜单

### 打开格式菜单

1. 在正文里选中一段文字。
2. 在选区上点击**鼠标右键**。
3. 菜单会出现在鼠标位置，并自动避开屏幕边缘。

没有选中文字时右键是浏览器默认菜单；选中文字后才会出现格式菜单。菜单里只有
**复制 / 剪切 / 粘贴 / 清除格式** 四项。

### 复制、剪切、粘贴

- **复制**：把选区内容复制到系统剪贴板。
- **剪切**：复制后从便签中移除选区。
- **粘贴**：把剪贴板内容插入当前光标位置。
- 如果浏览器拒绝剪贴板权限，菜单会保留并显示一行提示，而不是看起来没反应。

这些操作与系统快捷键等价，菜单方式适合鼠标操作。

### 清除格式

清除选区内的格式：粗体、斜体、下划线，以及从网页粘贴时带入的其他格式；文字本身保留。

### 快捷键

| 快捷键           | 作用                              |
| ---------------- | --------------------------------- |
| `Ctrl/Cmd` + `B` | 粗体                              |
| `Ctrl/Cmd` + `I` | 斜体                              |
| `Ctrl/Cmd` + `U` | 下划线                            |
| `Alt` + `↑`/`↓`  | 把聚焦的便签移动一格              |
| `Enter`          | 确认新建 / 重命名的便签名称       |
| `Esc`            | 取消新建 / 重命名，或关闭右键菜单 |
| `F2`             | 重命名当前聚焦的便签              |
| `Ctrl/Cmd` + `V` | 粘贴（自动清洗 HTML）             |

### 菜单关闭方式

点击菜单以外的任意位置、按 `Esc`、或滚动页面，菜单都会关闭。命令执行后编辑器会
重新获得焦点，可以继续输入。

## 6. 回收站

点目录底部的回收站按钮打开回收站面板（按钮上的数字徽标是当前回收站条数）。

- **列表**：显示已删除便签的标题和删除时间。
- **还原**：把便签放回目录，内容、置顶状态和创建时间都保留。
- **彻底删除**：第一次点击进入确认状态，再次点击才真正删除；该操作不可撤销。
- **清空回收站**：同样需要二次确认，清空后全部删除。
- **上限**：回收站最多保留 **100 条**；超出后最旧的记录会被自动丢弃。
- 点面板顶部的返回按钮回到便签列表。

## 7. 设置

点目录底部的齿轮按钮打开设置面板：

| 项目           | 说明                                                          |
| -------------- | ------------------------------------------------------------- |
| 字号           | 13–20 px（步进 1），默认 15 px，立即作用于编辑器正文          |
| 行高           | 1.4–2.0（步进 0.05），默认 1.75，立即作用于编辑器正文         |
| 主题           | 跟随系统 / 浅色 / 深色；固定后切换 DSH 主题不改变便签配色     |
| 恢复默认位置   | 把窗口移到 DSH 窗口右侧中间，保持当前尺寸                     |
| 同步状态       | 显示当前内容的保存位置与进度（见「同步状态小圆点」）          |
| 导出 JSON      | 下载当前全部便签和设置的 JSON 文件（`quick-notes-日期.json`） |
| 导入 JSON      | 选择之前导出的 JSON 文件，确认后恢复                          |
| 版本与项目链接 | 显示插件版本，点击可打开项目主页                              |

设置随便签一起保存。字号、行高和主题只影响便签界面显示，不改变便签内容。横线衬底
开关在目录底部（回收站右侧），不在本面板中。

主题说明：

- **跟随系统**：便签跟随 DSH 当前的明暗主题自动切换。
- **浅色 / 深色**：固定便签配色；此时在 DSH 设置里切换主题不会改变便签界面。
- 浅色主题下便签纸面是浅米黄色，横线也会跟着调整；深色主题使用对应的深色纸面。

## 8. 导入与导出

### 导出

1. 打开设置面板，点「导出 JSON」。
2. 浏览器会下载一个 JSON 文件，包含便签、回收站、设置和窗口状态。
3. 便签里的图片是内嵌的 data URL，因此带图片的备份文件会明显变大。
4. 把文件放到安全位置即可作为备份或迁移到另一台机器。

### 导入

1. 打开设置面板，点「导入 JSON」。
2. 选择之前导出的文件。
3. 第一次点击进入确认状态，再次确认后才会覆盖当前数据。
4. 导入成功后，目录、回收站和设置都会恢复为文件里的内容；导入失败会给出提示，
   当前数据保持不变。

导入会整体替换当前状态，操作前建议先导出一份当前数据。导入文件需要是本插件导出的
JSON；格式不符或文件损坏会被拒绝。

### 手动备份文件

除导出功能外，也可以直接复制数据文件 `notes.json`，详见
[`storage.md`](storage.md) 的「备份与恢复」一节。

## 9. 窗口操作与状态恢复

### 拖动

按住顶部移动条拖动整个窗口。拖动过程中窗口始终保持在屏幕可见范围内，至少保留一块
可点击的区域，不会拖到完全看不见。窗口顶部还会停在 DSH 窗口的 64 px 安全区以下（DSH
窗口很矮时会优先保证便签窗口完整可见），避免拖到 DSH 原生标题栏拖拽区时把整个 DSH
窗口拖走。

### 缩放

窗口四边和四角共有 8 个缩放手柄：

- 最小 320 × 240 px，最大不超过浏览器视口；
- 缩放时对角或对边保持不动，符合直觉；
- 窗口位置与大小会被记住。

### 恢复默认大小与位置

- **恢复默认大小**（标题栏第三个按钮）：把窗口宽高恢复为默认的 560 × 440，保持当前
  位置并夹在屏幕内，同时退出紧凑模式。
- **恢复默认位置**（设置面板里的按钮）：把窗口移到 DSH 窗口的右侧中间，保留当前
  尺寸并退出紧凑模式。
- 窗口默认初始位置也是 DSH 窗口的右侧中间，不会挡住左侧对话区域。

### 紧凑模式（仅便签）

点标题栏的「仅便签」按钮进入紧凑模式：

- 隐藏左侧目录，只保留标题栏和正文，窗口收窄；
- 原窗口大小会单独记下来；
- 再点「显示目录」恢复目录和原来的窗口大小。

紧凑模式适合对照资料写东西时把窗口收窄贴边使用。

### 最小化圆球

- 点标题栏的「缩成圆球」，窗口收成一个 56 px 的圆形悬浮球。
- 圆球只显示便签图标，没有便签数量角标。
- 圆球出现在**窗口右上角**（自动夹在视口内），并浮在其他插件挂件之上，不会被侧栏
  挂件挡住。
- 可以拖动圆球到屏幕任意位置，位置会被记住。
- **单击**圆球（按下和抬起之间移动很小）恢复窗口；拖动圆球不会触发恢复。
- 如果保存的圆球坐标非法或丢失，圆球会回退到右下角的可见位置，并夹在视口内。

### 隐藏与恢复

- 点侧栏底部的便签图标可以整体隐藏（窗口和圆球都不出现）。
- 再点一次恢复显示（默认回到普通窗口）。
- 隐藏状态会被保存，刷新页面后依然保持隐藏，直到再次点击侧栏图标。

### 状态恢复

窗口模式、窗口矩形、紧凑矩形、目录宽度和圆球位置都会随状态保存：

- 刷新页面、重启 DSH 后按保存的状态恢复；
- 如果换了显示器或分辨率变小，加载时会把越界的窗口拉回可见区域；
- 圆球同样会被限制在视口内，不会跑到屏幕外；
- 主题、横线衬底开关和便签顺序也会一起保存，刷新后保持。

### 同步状态小圆点

目录底部右侧的小圆点表示持久化状态：

- **正在连接…**：正在读取本地缓存和 Host 文件；
- **仅保存在本地**：Host 路由不可用，内容只保存在当前浏览器；
- **正在保存…**：正在写入 Host 文件；
- **已保存**：内容已经写入 Host 文件；
- **同步失败**：写入失败，内容仍保存在浏览器里，30 秒内会自动重试，期间新增修改也
  会重新触发保存。

## 10. 多标签页与多浏览器

- 插件没有跨标签页的实时同步。每个标签页只在打开时读取一次已保存状态。
- 同时打开多个标签页并编辑时，最后写入的标签页生效；其他标签页需要刷新才能看到
  最新内容。
- 换浏览器或换端口不会有影响，因为 Host 文件是共享来源；只要 Host 路由可用，新
  打开的页面会读到同一份数据。
- 如果 Host 路由不可用，内容只存在当前浏览器的 localStorage 里，不同浏览器之间
  不会互通。此时请先解决 Host 路由问题，或先用导出 JSON 迁移数据。
