# 随想随记 · 常见问题（FAQ）

本文对应 **1.0.0**（2026-11-02）。

## 数据相关

### 便签数据存在哪里？

分两处：

1. **Host 文件（主数据）**：`$DSH_HOME/quick-notes/notes.json`。没有设置 `DSH_HOME`
   时默认是 `~/.dsh/quick-notes/notes.json`（Windows 为
   `%USERPROFILE%\.dsh\quick-notes\notes.json`）。可以用环境变量
   `DSH_QUICK_NOTES_DIR` 改到别的目录。同目录下的 `diagnostics.log` 是插件诊断日志
   （挂载、主题 / 模式切换、圆球位置、同步对账等，不含便签正文）。
2. **浏览器镜像（兜底）**：`localStorage["dsh-quick-notes:state:v1"]`，只在 Host 路由
   不可用时作为数据来源，平时是主数据的副本。

详细格式与路由见 [`storage.md`](storage.md)。

### 刷新页面或重启 DSH 会丢数据吗？

不会。每次修改先在内存生效，停止输入约 500 ms 后统一写入浏览器本地镜像和 Host 文件；
页面离开前还会补一次写盘。刷新页面会重新读取已保存的状态，所以内容、回收站、设置和
窗口位置都会恢复。

### 换端口、换浏览器会不会丢？

不会，前提是 Host 路由可用：

- 换端口：数据在 Host 进程写的同一个文件里，与端口无关；
- 换浏览器：新浏览器会从 Host 路由读到同一份文件；
- 如果 Host 路由不可用（例如 Host 半身没加载），插件会退回 localStorage，此时数据
  只属于当前浏览器、当前源，换浏览器就读不到了。

### 为什么同步状态显示「仅本地」或「同步失败」？

「仅本地」表示浏览器连不上 Host 路由，当前只有 localStorage 镜像在工作；「同步失败」
表示写完本地后请求 Host 失败。常见原因：

1. 装完插件后没有重启 DSH，Host 半身的 HTTP 路由还没注册；
2. DSH 版本低于 0.2.0，插件不兼容；
3. 在浏览器的无痕 / 隐私模式里，Host 请求或 localStorage 被限制；
4. 数据目录不可写（权限问题或 `DSH_QUICK_NOTES_DIR` 指向只读位置）；
5. 通过反向代理访问，`Host` / `Origin` 被改写，请求被同源围栏拒绝。

排查顺序：先访问 `http://127.0.0.1:<DSH 端口>/dsh-quick-notes/health` 看 Host 半身
是否在线，再看 DSH 启动日志里 `dsh-quick-notes:` 开头的行，最后检查数据目录权限。

### 为什么需要 Host 路由？只用 localStorage 不行吗？

只用 localStorage 的话，数据被绑定在「某个浏览器 + 某个源（协议 + 主机 + 端口）」上：
换浏览器、清站点数据、换端口都会看不到，也没法直接备份成一个文件。Host 路由把数据
写成 `$DSH_HOME` 下的普通 JSON 文件，于是：

- 跨端口、跨浏览器共享同一份数据；
- 可以直接备份 / 迁移 / 用文本编辑器查看；
- Host 不可用时 localStorage 仍然兜底，功能不中断。

### 可以做网络同步 / 云同步吗？

不会。插件不向外网发请求、没有账号、没有遥测；数据只在本机的 Host 文件和浏览器本地
存储里。需要多机同步时，请手动导出 / 导入 JSON，或自行同步数据目录（注意同时修改会
互相覆盖）。

## 备份与迁移

### 如何备份便签？

两种方式：

1. **设置 → 导出 JSON**：下载一份完整状态（便签、回收站、设置、窗口状态），适合长期
   保存和迁移；
2. **复制数据文件**：关闭 DSH 后复制 `$DSH_HOME/quick-notes/notes.json`。

### 如何恢复或迁移到另一台电脑？

- 在本机恢复：**设置 → 导入 JSON**，选之前导出的文件并确认；
- 迁移：在新机器上安装插件并重启 DSH，然后在设置里导入 JSON；或者关闭 DSH 后把
  `notes.json` 放到新机器对应的数据目录里再启动。

导入会整体覆盖当前数据，操作前建议先导出一份当前状态。

### 如何彻底卸载并清理数据？

插件卸载不会自动删除数据文件，需要手动清理：

1. **停用 / 卸载插件**：设置 → 插件里停用或卸载「随想随记」；命令行安装的也可以按
   DSH 文档用 `dsh plugin` 命令移除；
2. **删除数据目录**：关闭 DSH 后删除 `$DSH_HOME/quick-notes/`（或
   `DSH_QUICK_NOTES_DIR` 指向的目录）；
3. **清理浏览器镜像**：DevTools → Application → Local Storage，删除
   `dsh-quick-notes:state:v1`，或清除该站点的存储；
4. 重启 DSH。

如果只删文件不删 localStorage，下次启动浏览器可能把本地镜像又推回 Host，看起来像
「删了又回来」。建议先导出备份，确认不需要后再清理。

### 如何重置为空便签本？

按上面的清理步骤删除数据文件和 localStorage，重启后就是全新的空状态。只想清空内容
的话，也可以逐条删除便签再清空回收站。

## 使用相关

### 怎么安装、怎么更新？

安装有四种方式：

1. **DSH 界面**：打开左侧栏的 **插件（Plugins）** 页 → **添加插件（Add plugin）** →
   **安装第三方插件（Install a third-party plugin）**，填 `dsh-quick-notes` 并确认；
2. **插件市场**：在 **插件 → 发现** 标签页（配置了索引源时）或社区 dshmarket 插件的
   **设置 → 插件市场** 里搜索「随想随记」（或 **Quick Notes**），点安装；
3. **命令行**：`dsh plugin --profile web add dsh-quick-notes`（`web` 换成你的
   profile 名称）；
4. **本地代码**：在 **插件页 → 添加插件 → 安装第三方插件** 里选择仓库目录，或
   `dsh plugin add link:/本目录的绝对路径`。

装好后如果窗口或侧栏图标没有出现，重启一次 DSH。更新时在插件页/市场里更新，或再执行
一次 `dsh plugin add dsh-quick-notes` 并重启 DSH 即可，数据文件不会被覆盖。

### 便签数量和长度有限制吗？

有：

- 目录最多 **500 条**便签，达到上限后无法继续新建，需要先删除一些便签；
- 回收站最多 **100 条**，超出后最旧的自动丢弃；
- 便签名称最长 **80 个字符**；
- 单条便签的 HTML 最多 **60 万个字符**（内嵌图片也算在内）；
- 一次保存的请求体最大 **8 MiB**。

### 多标签页同时打开会怎样？

没有实时同步。每个标签页打开时读取一次已保存状态，之后的修改各自保存；两个标签页
同时编辑时，最后写入的覆盖前面的。建议同一时间只用一个标签页编辑，其他标签页刷新后
即可看到最新内容。

### 为什么右键菜单没有高亮 / 字体颜色了？

高亮和字体颜色已按产品要求移除，右键菜单现在只保留 **复制 / 剪切 / 粘贴 / 清除格式**
四项。需要强调文字时可以用 **Ctrl/Cmd + B / I / U** 加粗、斜体和下划线；「清除格式」
会去掉选区内的粗体、斜体、下划线，以及从网页粘贴时带入的其他格式。以前保存的便签里
如果已经有历史颜色标记，仍会照常显示，只是不能再新增这类格式。

从网页粘贴的内容仍会先经过清洗：白名单之外的标签（外链图片、链接、脚本、iframe 等）、
事件属性和不认识的样式都会被剥离，所以粘贴后看起来「格式变少了」是正常的，这是安全
设计。粘贴图片文件本身会走图片通道压缩后内嵌，不受这条限制。拖放内容进编辑器与粘贴
使用同一份白名单。

### 为什么我的便签主题和 DSH 主题不一样？

插件有自己的调色板，设置 → 主题里有三档：

- **跟随系统**：便签跟随 DSH 当前的明暗主题；
- **浅色 / 深色**：固定便签配色。此时在 DSH 设置里切换主题**不会**改变便签界面。

所以如果便签一直保持浅色（或深色）而 DSH 已经换了主题，多半是之前选了固定主题。
打开 **设置 → 主题 → 跟随系统** 即可恢复跟随。浅色主题的便签纸面是浅米黄色，属于
产品设计，不是显示异常。

### 缩成圆球后圆球在哪里？

点标题栏「缩成圆球」后，圆球出现在**原窗口的右上角**（会夹在视口内），而不是屏幕
右下角；圆球只显示图标，没有便签数量角标。圆球层级高于其他插件挂件，正常情况不会
被挡住。找不到时：

1. 刷新页面，窗口会按保存的模式恢复，圆球会按保存位置或回退位置重新出现；
2. 如果位置数据损坏，插件会回退到右下角的可见位置并夹在视口内；
3. 排查时看 `$DSH_HOME/quick-notes/diagnostics.log` 里的 `ball.mounted` 记录，里面有
   圆球坐标与视口尺寸；
4. 仍然异常时，用 **设置 → 导出 JSON** 检查 `ui.ball` 的 `x` / `y`，修正后导入。

### 粘贴的图片为什么变小了？

图片被内嵌进便签前会自动压缩，目的是让一张截图既能看清，又不会撑破窗口或撑爆文件：

- 先按等比把最长边缩到不超过 **1024 px**；
- 如果生成的 data URL 超过大小预算（约 45 万字符），会继续按比例缩小，最低到 320 px；
- PNG / WebP / GIF 输入按 PNG 保存（保留可能的透明通道），JPEG 输入按 JPEG（质量约
  0.82）保存；
- 动态 GIF / WebP 只保留第一帧。

图片是便签 HTML 的一部分（`data:` URL 内嵌，没有独立附件），所以单条便签的 60 万字符
上限也包含图片；多张图片累计超过上限时，后面的图片会被静默跳过。

### 为什么外链图片 / SVG 显示不出来？

出于安全和隐私考虑，插件只接受**内嵌的位图数据**（PNG / JPEG / WebP / GIF 的
`data:image/...;base64,`）：

- `http(s)` 外链图片会在保存 / 粘贴清洗时被移除，避免加载追踪像素或远程资源；
- SVG 属于可执行脚本的格式，直接拒收；
- 协议相对地址、`javascript:` 等同样会被清洗。

需要保留网页上的图片时，先把它保存成本地图片文件，再粘贴或拖进编辑器。

### 窗口为什么拖不到最顶上？

DSH 桌面窗口顶部有一条**原生标题栏拖拽区**。如果便签窗口能盖到那里，用户按住顶部
拖动时就会变成拖动整个 DSH 窗口。因此插件把便签窗口限制在顶部 **64 px 安全区**以下
（`y ≥ 64`；DSH 窗口本身很矮时会优先保证便签窗口完整可见）；这是有意设计，不是拖动
失灵。需要更靠上的位置时，可以把 DSH 窗口本身往上移，或用「恢复默认位置」把便签放回
右侧中间。

### 支持导出 Markdown 或纯文本吗？

当前版本只支持 JSON 导出 / 导入，没有 Markdown 或纯文本导出。需要纯文本时，可以手动
从编辑器复制内容。

### 窗口或圆球跑到屏幕外了怎么办？

插件在加载和浏览器窗口尺寸变化时会把窗口矩形、圆球位置拉回可见区域；最小化后的圆球
落在窗口右上角，坐标异常时会回退到右下角可见位置。所以先刷新页面或稍微缩放一下浏览器
窗口；如果只是窗口位置乱了，最快的方法是 **设置 → 恢复默认位置**。仍然找不到时，可以
走高级恢复：

1. 设置 → 导出 JSON，得到当前状态文件；
2. 用文本编辑器打开，把 `ui.rect` / `ui.ball` 改成屏幕内的合理值；
3. 设置 → 导入 JSON 恢复。

排查圆球位置可以看 `diagnostics.log` 里的 `ball.mounted` 记录（包含坐标与视口尺寸）。
如果窗口位置反复异常，请带上 `ui.rect` 的值和显示器配置到 Issues 反馈。

### 界面显示「随想随记渲染失败」怎么办？

这是插件的错误边界兜底：某个组件渲染崩溃时，浮窗位置会显示这条提示，避免整块界面
空白。处理方式：

1. 刷新页面，多数临时错误会消失；
2. 如果反复出现，查看 `$DSH_HOME/quick-notes/diagnostics.log`：里面有挂载、主题、
   模式、同步等诊断记录和错误堆栈（不含便签正文）；
3. 带上日志内容和复现步骤到 Issues 反馈。

### 插件会影响 DSH 的其他功能吗？

不会。插件只做两件事：在 `shell.overlay` 里渲染浮窗、在 `sidebar.footer.action` 里加
一个入口按钮，并在 Host 侧注册自己的状态读写路由和健康检查路由。它不修改 DSH 的
设置、会话或消息。

### 支持哪些语言？

界面文案内置英文和中文，跟随 DSH 当前语言显示；插件管理器里的标题和描述也提供了
中英两份（`locale/en.json`、`locale/zh.json`）。

### 数据加密吗？

不加密。数据文件是可读 JSON，浏览器镜像也是明文。便签内容敏感时请使用系统磁盘加密，
并在共享电脑上注意浏览器配置文件的访问权限。
